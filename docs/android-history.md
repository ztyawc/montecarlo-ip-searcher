# Android 结果保存与历史记录

版本：0.4.1+5。日期：2026-09-08。

## 使用

扫描结束后自动保存记录。重新打开应用时，“结果”页会显示最新一条历史；在“结果 → 历史记录”中可查看其他扫描。开始新扫描会保留上一轮，也可以在扫描期间浏览历史，再通过“查看本次扫描”返回实时结果。

每条记录包含开始与结束时间、域名、IPv4/IPv6、状态、完成数量、有效 IP 结果和统计。结果仍可复制和打开 IP 详情。查看历史不会恢复旧参数，也不会替换当前扫描的进度、结果或日志。

自动保留最近 50 次扫描，超出后移除最早的记录。单条删除需要确认，删除失败会保留原记录。记录保存在应用私有目录，无需额外存储权限；卸载应用或清除应用数据会删除历史。应用备份继续关闭，记录不会上传。

## 保存与异常恢复

Android 原生层负责保存，界面订阅结束事件不是保存的前提。扫描开始时写入检查点，收到结果后合并为约 2 秒一次更新；完成、停止或退出时保存最终状态。应用异常终止后，已落盘的检查点作为“已中断”记录显示。尚未由扫描核心输出、或尚未写入文件的结果无法恢复。

扫描仍需保持前台，重开应用只恢复历史查看，不自动继续扫描。

历史文件使用版本化格式和临时文件原子替换。写入失败保留此前文件；最终保存失败时，若已有检查点，则显示最近保存的“已中断”记录并提示。读取失败可刷新重试；损坏或不支持的文件不会被空记录覆盖，只有成功读取后才能继续写入。

保存内容采用字段白名单：只保存扫描摘要、有效 IP 结果、测速数值、机房编号与数值统计。密码、代理配置、完整 URL、日志及原始错误文本不进入历史文件；测速失败使用通用提示。单条记录最多保存 1000 个结果，与扫描参数上限一致。

## 验证范围

Flutter 测试覆盖重新打开后的恢复、历史与实时扫描隔离、并发读取、错误重试、删除确认和失败处理，以及窄屏、大字体、长域名与 IPv6 显示。

原生测试使用真实临时文件，覆盖读写一致性、保留数量、完整结果、字段过滤、进程重建后的中断恢复、读写失败重试、最终保存失败回退、删除失败、损坏格式和原子替换。测试命令见 [Flutter 说明](../flutter-app/README.md)。

本机已通过 Flutter 静态分析、22 项 Flutter 测试、61 项原生场景（含 30 项新增历史文件场景），以及 200 次进程停止与启动的并发检查。尚未进行 Android 真机验证。
